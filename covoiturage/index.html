Aide rapide

1. Renseignez le trajet, puis cliquez sur Calculer et chercher.

2. Consultez les collègues classés du plus pertinent au moins pertinent et cliquez sur une proposition pour afficher le détour.

3. Cliquez sur Publier le trajet : l'enregistrement se fait directement sur cette page.

Retrait : le bouton Supprimer apparaît sur les trajets publiés depuis ce navigateur.

Confidentialité : l'application doit être déployée avec un accès limité aux comptes de l'entreprise.
